# 订阅与余额

## 订阅套餐

档位照官方订阅划分，档与档之间的用量比例也照官方：

| 平台 | 档位 | 对标官方 | 相对用量 |
|---|---|---|---|
| Claude | Claude Pro | Claude Pro | 1× |
| Claude | Claude Max 5x | Claude Max 5x | 5× |
| Claude | Claude Max 20x | Claude Max 20x | 20× |
| OpenAI | Codex Plus | ChatGPT Plus | 1× |
| OpenAI | Codex Pro | ChatGPT Pro | 5× |

价格、有效期、每档的额度以控制台「购买订阅」页显示为准。

### 额度怎么算

- 额度以**美元**计，每次请求按该模型的官方 API 标准价折算后扣减
- 每档有**每日**和**每周**两道上限，任一用完就暂停，到下一个周期自动恢复
- 订阅期内不扣账户余额

所以同样的额度，用缓存命中率高、输出短的请求能用得更久。

### 一个密钥只对应一档

创建密钥时选的分组决定它走哪一档的额度。Claude 和 Codex 是不同的档，要各建一个密钥。

## 余额

余额按 token 实时扣费，用于按量计费的分组。可在「兑换」页用余额兑换码充值。

订阅和余额互不抵扣：用订阅档位的密钥不扣余额，余额也不能用来抵订阅额度。
