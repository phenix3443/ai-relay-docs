# 快速开始

四步接入：注册 → 开通订阅 → 创建密钥 → 配置客户端。

控制台地址：<https://relay.panghuli.tech>

## 1. 注册

打开控制台，点「注册」。注册需要**邀请码**，没有的话先[联系我们](./contact)。

## 2. 开通订阅

在左侧菜单进入「充值/订阅」，切到「订阅」，选一个套餐购买。
也可以在「兑换」页输入订阅兑换码开通。

开通后在「我的订阅」能看到套餐、有效期和本周已用额度。

套餐怎么选，见[订阅与余额](./billing)。

## 3. 创建 API 密钥

进入「API 密钥」→「创建密钥」，**分组选你订阅的那一档**（例如 Claude Max20x）。

::: tip 分组列表里没有我买的那档？
订阅类分组只有在订阅生效后才出现在可选列表里。先确认「我的订阅」里有这一档且未过期。
:::

::: warning 保管好密钥
密钥等同于你的账号额度，不要发到群里、不要提交到代码仓库。泄露了就在「API 密钥」里删掉重建。
:::

## 4. 配置客户端

在「API 密钥」列表里，每个密钥后面有两个按钮：

- **使用密钥**：按你的系统（macOS / Linux / Windows）生成 Claude Code、Codex CLI 的配置，复制即可
- **导入到 CCS**：已安装 [CC Switch](../clients/cc-switch) 的话，一键导入

分客户端的详细说明：

- [Claude Code](../clients/claude-code)
- [Codex CLI](../clients/codex)
- [CC Switch 一键导入](../clients/cc-switch)

## 5. 查看用量

- 「我的订阅」：本周、今日已用额度和剩余额度
- 「使用记录」：每一次请求的模型、token 数和折算费用
